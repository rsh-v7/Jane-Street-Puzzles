# Jane Street Monthly Puzzles

This repo has my solutions to Jane Street's monthly puzzles. I solve them myself, then write up how I got to the answer along with the code I used to finish it off.

## A note on timing

I only add a puzzle's write up here after Jane Street has posted their own official solution for it. Their puzzles stay open through the end of the month they're posted in, and other people are usually still working on the current one, so I hold off putting mine up until it's actually closed.

## How each folder is set up

Every puzzle folder has the same three things:

- a README with the puzzle explained in plain words and how I worked through it
- the code I used to solve it
- steps on how to run it yourself

## Tools

Mostly just Python. Some puzzles take a lot of work on paper before any code gets written. The July one especially needed a lot of hand math before I started coding anything at all, the code only took over once the manual work had narrowed things down enough.
